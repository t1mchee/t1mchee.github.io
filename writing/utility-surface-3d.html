Utility surface in 3D

April 2026

Most micro diagrams show indifference curves and budget lines in the plane, as if the object of interest were a flat map. The map is really a projection: those curves are level sets of a utility function \(U(x_1,x_2)\) that lives in a third dimension. We rarely draw that height, so it is easy to forget what “moving along an indifference curve” or “tangent to the budget” means in the geometry of the surface. I think that missing picture is an underappreciated source of confusion when we lean on two-dimensional graphs alone.

The interactive view below is the same tool as the standalone project ev-cv-3d (also hosted here): a coloured utility “hill”, horizontal slices as indifference curves, the budget as a vertical curtain, and the Marshallian optimum on the surface. It is meant as intuition alongside the usual 2D EV/CV diagrams, not as a substitute for welfare measured in money units.

How to use it

  • 3D / 2D toggles perspective; drag to rotate in 3D, scroll to zoom.
  • Mode (numbered tabs) switches scenarios: surface overview, Slutsky/Hicksian/Marshallian stories, ordinality transforms, and a parallel EV/CV curtain view.
  • Utility is Cobb–Douglas or CES; use the sliders for \(\alpha\) (and \(\rho\) for CES).
  • Prices and income drive the budget plane; each mode adds its own toggles and sliders at the bottom of the panel.

If the frame stays blank, open the standalone demo in a new tab. The embed is same-origin on GitHub Pages so it should load here once the script bundle is available.
